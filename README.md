# La Maglia - Toko Jersey Bola

Final Project Study Club Front End Basic (KSM Veterantech UPNVJ 2026).

Website toko online jersey bola bergaya Italia, dibuat dengan HTML, CSS, dan JavaScript biasa (tanpa framework).

## Struktur file
- `index.html` : katalog jersey + filter liga
- `produk.html` : detail jersey (slider foto, pilih ukuran, tambah ke keranjang), dibuka lewat `produk.html?id=...`
- `keranjang.html` : keranjang belanja
- `style.css` : seluruh tampilan
- `script.js` : seluruh interaksi JavaScript
- `img/` : foto jersey (3 foto per produk)

## Fitur
- Semantic HTML (`header`, `aside`, `nav`, `main`, `section`, `footer`)
- Responsif untuk HP, tablet, dan desktop (CSS Grid + Flexbox)
- Interaksi JavaScript (DOM): sidebar menu, filter liga, halaman detail dinamis, ukuran, keranjang, total harga, mode terang/gelap
- Keranjang dan tema tersimpan di localStorage

## Cara menjalankan
Buka `index.html` di browser (atau gunakan Live Server di VSCode).
